# Rinrada-Dev Portal

หน้าเว็บรวมระบบที่ติดตั้งให้องค์กรได้ เป็นเว็บ static ล้วน ไม่มีขั้นตอนบิลด์ เปิด `index.html` ในเบราว์เซอร์ได้ทันที

| ไฟล์ | คืออะไร |
| --- | --- |
| `index.html` | เนื้อหาทั้งหน้า |
| `styles.css` | หน้าตา: กระดานแผ่นสีเรียบ ห่างกัน 8px, ฟอนต์ Jost (ละติน) กับ Prompt (ไทย) |
| `main.js` | เครื่องคิด markup/margin, ปุ่มกรองระบบ, ฟอร์มที่เปิดอีเมล, นาฬิกากรุงเทพฯ และ animation ตอนเลื่อนหน้า |
| `assets/shots/` | ภาพหน้าจอจริงของแต่ละระบบ (WebP) และคลิปพิมพ์ชื่อบนเกียรติบัตรจากเดโม QREMS |

ถ้าปิด JavaScript หน้ายังอ่านได้ครบ เครื่องคิดแสดงตัวอย่าง markup 20% = margin 16.67% และฟอร์มส่งผ่าน `mailto:` ตรงๆ

## ก่อนขึ้นเว็บ

เปลี่ยนอีเมล `you@example.com` เป็นอีเมลจริง มีอยู่ 2 ไฟล์:
- `index.html` (ลิงก์นัดดูเดโม, ฟอร์มติดต่อ และท้ายหน้า)
- `main.js` บรรทัด `const EMAIL = ...`

## Deploy

เหมือน QREMS-Demo: push โฟลเดอร์นี้ขึ้น GitHub แล้ว import เข้า Vercel โดยไม่ต้องตั้งค่าอะไร โฟลเดอร์ `.taste-skill/` (ภาพที่ใช้ตรวจตอนออกแบบ) ถูก ignore ไว้แล้ว

## อัปเดตเนื้อหา

- **ลิงก์เดโม QREMS:** `https://qrems-demo.vercel.app` อยู่ใน `index.html` 3 ที่
- **โค้ด Happy Paws:** ลิงก์ไป repo สาธารณะ `MildRinrada/Happy-Paws-Clinic-Demo`
- **ระบบเทียบราคา:** repo เป็น private จึงมีแค่ปุ่มนัดดูเดโมทางอีเมล ถ้าทำเดโมออนไลน์แล้ว ให้เปลี่ยนลิงก์ปุ่มนั้น และเปลี่ยน `data-live="no"` ของแถบภาพระบบนี้เป็น `"yes"` เพื่อให้ขึ้นในตัวกรอง "มีเดโมออนไลน์"
- **ภาพหน้าจอ:** วางไฟล์ใหม่ทับชื่อเดิมใน `assets/shots/` ได้เลย
  - ภาพ QREMS จับจากเดโมโดยซ่อนแถบเดโม
  - ภาพระบบเทียบราคามาจาก `docs/manual/images`
  - ภาพ Happy Paws มาจาก `docs/images` ของแต่ละโปรเจกต์
- **ข้อมูลในใบติดตั้ง** (หัวข้อ "วิธีทำงาน") เป็นตัวอย่าง เช่น สมาคมตัวอย่าง และ events.example.or.th
