# Rinrada-Dev Portal

หน้าเว็บรวมระบบที่ติดตั้งให้องค์กรได้ เป็นเว็บ static ล้วน ไม่มีขั้นตอนบิลด์ เปิด `index.html` ในเบราว์เซอร์ได้ทันที

| ไฟล์ | คืออะไร |
| --- | --- |
| `index.html` | เนื้อหาทั้งหน้า: หน้าแรก, การ์ดรวม 3 ระบบ, ส่วนของแต่ละระบบ, วิธีทำงาน, ติดต่อ |
| `styles.css` | หน้าตา: พื้นขาว สีหลักน้ำเงินเข้ม ฟอนต์ IBM Plex Sans Thai |
| `main.js` | กดภาพหน้าจอแล้วขยายเต็มภาพ, ฟอร์มที่เปิดอีเมล, เฟดเข้าตอนเลื่อนหน้า |
| `assets/shots/` | ภาพหน้าจอจริงของแต่ละระบบ (WebP) และคลิปพิมพ์ชื่อบนเกียรติบัตรจากเดโม QREMS |

ถ้าปิด JavaScript หน้ายังอ่านได้ครบ และฟอร์มส่งผ่าน `mailto:` ตรงๆ

## อีเมล

อีเมลติดต่อคือ mildppgd@gmail.com อยู่ใน `index.html` (ปุ่มนัดสาธิต, ส่วนติดต่อ และฟอร์ม) และ `main.js` บรรทัด `const EMAIL = ...` ถ้าเปลี่ยนต้องแก้ทั้งสองไฟล์

ห้ามใช้ em dash (—) และจุดกลาง (·) ในข้อความบนหน้า ใช้จุลภาคหรือเว้นวรรคแทน

## Deploy

push โฟลเดอร์นี้ขึ้น GitHub แล้ว import เข้า Vercel โดยไม่ต้องตั้งค่าอะไร

## เพิ่มหรือแก้ระบบ

- **โครงของแต่ละระบบใน `index.html`:** ทุกระบบใช้ `<section class="sys">` แบบเดียวกัน ประกอบด้วย
  - ชื่อ
  - "สำหรับใคร"
  - ข้อดี 4 ข้อ
  - ปุ่ม
  - เทคโนโลยี
  - ภาพหลัก 1 ภาพ และภาพเล็ก 3 ภาพ
- **เพิ่มระบบใหม่:** คัดลอกหนึ่งชุด แล้วเพิ่มการ์ดในส่วน "ระบบที่มี" ด้วย
- **สลับภาพไปซ้าย:** ใส่ `sys--flip`
- **หัวข้อภาษาไทย:** ครอบวลีด้วย `<span class="nw">` เพื่อไม่ให้ตัดบรรทัดกลางคำ
- **ระบบที่มีเดโมออนไลน์:** การ์ดใช้ `status status--live` (จุดสีเขียว) และปุ่มหลักเป็น "ลองเดโม"
- **ระบบที่เดโมยังไม่เสร็จ:** ใช้ปุ่ม `disabled` "เดโมเร็วๆ นี้" และสถานะในการ์ดแบบไม่มี `status--live`
- **ลิงก์เดโม:** ใช้ลิงก์ถาวรของโปรเจกต์บน Vercel เสมอ
  - QREMS: `https://qrems-demo.vercel.app`
  - ระบบเทียบราคา: `https://spcs-demo.vercel.app`
  - คลินิก Happy Paws: `https://clinic-web-demo-seven.vercel.app`
  - ห้ามใช้ลิงก์ของ branch เช่น `qrems-demo-git-main-rinrada-dev.vercel.app` เช่นกัน Vercel ล็อกไว้ให้คนในทีมเท่านั้น
  - ห้ามใช้ลิงก์ที่มีรหัสต่อท้าย เช่น `qrems-demo-qsv5szlok-...vercel.app` เพราะเป็นลิงก์ของการ deploy ครั้งเดียว Vercel ล็อกไว้ให้เจ้าของเท่านั้น คนอื่นจะเจอหน้าล็อกอิน
- **ภาพหน้าจอ:** วางไฟล์ใหม่ทับชื่อเดิมใน `assets/shots/` ได้เลย
